# CVAT 新手指南：Clip 6 A 段（第一個 10 秒標註任務）

本文件是 Clip 6 A 段的操作入門。完整的標註規則（框要包到哪裡、哪些人要標）請看 [ANNOTATION_GUIDE.md](ANNOTATION_GUIDE.md)。本文只講第一個任務的實際操作。

> 畫面上的框、Track ID 和球的位置都是系統自動產生的**草稿**，不是真值。你檢查並修正一條軌跡後，再把它設成 `reviewed`。只要還有任何一條軌跡是 `unreviewed`，評估程式就會拒絕使用這份標註。

## 0. 每次開始前

1. 從開始選單開啟 **Docker Desktop**。等左下角狀態變成綠色的 **Engine running**，大約 30–60 秒。
   - CVAT 的容器會自動跟著啟動，不需要輸入任何指令。
2. 用瀏覽器（Chrome 或 Edge）開啟 **http://localhost:8080**。
3. 登入：
   - 帳號：`admin`
   - 密碼：在 `D:\external\cvat_admin.txt` 的第二行
   - 登入後可以在右上角帳號選單修改密碼。

## 1. 打開任務

1. 上方選單點 **Tasks**，會看到任務 **clip6_A_identity**（任務 #1，共 600 幀）。
2. 點任務名稱進入任務頁面，下方 **Jobs** 列表有一個 **Job #1**。點它就會進入標註畫面。

你應該會看到：

| 標籤 | 數量 | 外觀 |
|---|---|---|
| `player` | 17 條軌跡 | 紅色框，`team` 屬性是 A（湖人，紫色）或 B（金塊，白色） |
| `referee` | 5 條 | 深灰色框 |
| `other_person` | 1 條 | 灰色框 |
| `ball` | 1 條 | 橘色點 |

如果畫面上沒有框，請告訴我。

## 2. 移動影格

| 操作 | 快捷鍵 / 位置 |
|---|---|
| 下一幀 / 上一幀 | **F** / **D** |
| 往前 / 往後跳 10 幀 | **V** / **C** |
| 播放 / 暫停 | **Space** |
| 跳到指定幀 | 畫面上方中間的幀號欄，輸入數字後按 Enter（0–599） |
| 放大 / 移動畫面 | 滑鼠滾輪縮放；按住滑鼠右鍵或中鍵拖曳 |

**建議做法**：一次只檢查一條軌跡。右側 **Objects** 清單裡，點其他物件的眼睛圖示把它們隱藏起來，按 F 一路往前，看框是否一直跟著同一個人。

## 3. 修正框的位置

- 選取框之後拖曳框本身或四個角。
- 你修改的那一幀會自動變成**關鍵幀**（Objects 清單裡的星號圖示亮起）。CVAT 會在相鄰的關鍵幀之間自動內插。
- 草稿每 5 幀有一個關鍵幀，通常只需要修幾個地方。
- 球員被擋住時，仍然要畫出完整身體，並按 **Q**（Occluded）。
- 球員離開畫面或完全看不到時，在他消失的第一幀按 **O**（Outside）。重新出現時，到那一幀再按一次 O，然後把框拉到正確位置。

## 4. 修正換號（ID swap）

例子：第 120 幀之前，Track 5 是 #15 白衣球員。兩人交錯之後，Track 5 跑到另一個人身上。

1. **找出第一個錯誤的幀**，例如第 121 幀。
2. **切開錯誤的軌跡**：
   - 左側工具列選 **Split**（剪刀圖示，快捷鍵 **Alt+M**）。
   - 在第 121 幀點 Track 5 的框，它會分成兩條：121 幀之前和之後。
   - 另一位球員的軌跡如果也換錯了，同樣在第 121 幀切開。
3. **把正確的段接起來**：
   - 左側工具列選 **Merge**（快捷鍵 **M**）。
   - 先點同一個人「前一段」的框，再跳到後面的幀點他「後一段」的框。
   - 再按一次 **M** 完成合併。
4. 如果某一段根本是錯的人（例如觀眾），直接選取那段軌跡按 **Delete**。

> 系統已經在它懷疑換人的位置把軌跡先切開了。如果你看了之後判斷其實沒換人，用 Merge 把兩段接回去就好。

## 5. 刪除或改標錯的人

| 情況 | 怎麼做 |
|---|---|
| 看台上的觀眾 | 選取後按 **Delete**（會刪掉整條軌跡） |
| 站在場邊地板上的教練、板凳球員、工作人員 | 在 Objects 清單把標籤改成 `other_person` |
| 球員被標成裁判，或反過來 | 改標籤：`player` / `referee` |
| 隊伍標錯 | 展開該物件（點左邊小箭頭），把 `team` 改成 A 或 B |

已知的系統錯誤例子：
- 第 300 幀右下的 45 號裁判被標成 player A。
- 第 540 幀右下角有一位前排觀眾被標成 player B。

## 6. 漏掉的人

1. 左側工具列選**矩形**工具。
2. 標籤選 `player`（或 `referee`），按 **Track**。
3. 在畫面上拉出框。
4. 往後跳幾幀，拖曳框到正確位置，CVAT 會自動補中間的幀。
5. 人消失時按 **O**。

## 7. 球

- 球是一條橘色點的軌跡，標籤 `ball`。
- 點的位置錯了就直接拖曳；看不到球的那一幀按 **O**。
- 球重新出現時，在那一幀按 O 取消 Outside，並把點放到球上。
- `state` 屬性：
  - `visible`：清楚可見
  - `partly_hidden`：部分被擋住
  - `estimated`：被擋住，只能估計位置
- 漏掉的球：左側工具列選 **Points**，標籤 `ball`，按 **Track**，點在球上。

## 8. 標記已審核

一條軌跡從頭到尾都檢查並修正完之後：
1. 在 Objects 清單展開它。
2. 把 `review` 從 `unreviewed` 改成 **`reviewed`**。

建議最後把清單裡所有軌跡都確認一次。

## 9. 存檔與匯出

- **存檔**：隨時按 **Ctrl+S**，或按左上角的存檔圖示。工作會存在本機的 CVAT 資料庫（在 D:），下次打開會接著做。
- **匯出**（全部完成後）：
  1. 回到任務頁面，右上角 **Actions** → **Export task dataset**。
  2. Export format 選 **CVAT for video 1.1**，不要勾 Save images，按 OK。
  3. 上方選單 **Requests** 頁面會出現匯出完成的項目，點 **Download** 下載 zip。
  4. 把下載的 zip 移到 `data\annotations\clip6_A_identity\gt_cvat_export.zip`，然後告訴我，我會跑評估。

## 10. 關閉

- 存檔後直接關掉瀏覽器即可。
- 不用時可以結束 Docker Desktop（右下角系統匣圖示 → Quit），釋放記憶體。實測 CVAT 容器約用 3.2 GB，整個 WSL 虛擬機（工作管理員裡的 vmmemWSL）約 7.6 GB。下次開啟 Docker Desktop，CVAT 會自動恢復，資料不會遺失。

## 11. 打不開時的處理

| 狀況 | 原因 | 處理 |
|---|---|---|
| 網頁「無法連線」 | Docker Desktop 沒有在執行（開機後不會自動啟動） | 開啟 Docker Desktop，等 1–2 分鐘再重新整理 |
| 網頁顯示 **502 Bad Gateway**，一直不好 | 電腦不正常關機（例如沒電、強制重開機）後，CVAT 的佇列資料庫 Redis 檔案損壞 | 請 Claude 處理，或照下面步驟自己修 |

2026-10-16 實際發生過一次 502 的情況，修復步驟如下：
1. 先備份標註資料庫。
2. 用 Redis 內建工具修掉損壞的最後 212 bytes。
3. 重新啟動 Redis。

修完後確認：你的 6501 個框完全沒變。

**你的標註存在 PostgreSQL 資料庫（`cvat_db`），不在 Redis。** 備份放在 `D:\external\cvat_backups\`。

自己修復的指令（在 PowerShell 執行）：
```
docker stop cvat_redis_inmem
docker run --rm -v cvat_cvat_inmem_db:/data redis:7.2.11-alpine sh -c "cd /data/appendonlydir && yes | redis-check-aof --fix appendonly.aof.manifest"
docker start cvat_redis_inmem
```

**避免這個問題的方法**：關機前先在 CVAT 存檔，再從右下角系統匣結束 Docker Desktop（Quit）。
